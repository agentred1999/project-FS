## ⚙️ Getting Started

Clone the repository:

```bash
git clone git@github.com:agentred1999/project-FS.git
```

Navigate to the repository:

```bash
cd project-FS
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run start
```
